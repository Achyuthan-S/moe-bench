# MoE-Bench Documentation

Open benchmark for expert collapse and routing efficiency in sparse MoE LLMs.

## Getting Started

```bash
pip install moe-bench
moe-bench analyze --model mistralai/Mixtral-8x7B-Instruct-v0.1 --dataset combined --output results.json
```

See [API Reference](api.md) and [Contributing a Model](contributing.md).
